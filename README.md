📁 File Organiser
A lightweight Python CLI tool that automatically organises messy folders by sorting files into categorised subfolders — in seconds!

🎯 Goal of the Project
The goal of this project is to automate the boring and time-consuming task of manually sorting files. Instead of dragging files one by one, this tool scans a folder and instantly moves files into the correct subfolders based on their file type — with zero errors.

⚙️ Tools & Technologies Used
Tool	Purpose
Python 3	Core programming language
os module	Folder scanning and path handling
shutil module	Moving files across directories
sys module	Reading command line arguments
VS Code	Code editor
✨ Features
✅ Auto-scans any folder
✅ Detects file types by extension
✅ Creates subfolders automatically
✅ Moves files into correct category
✅ Duplicate file detection
✅ Dry run mode — preview before moving
✅ Summary report after every run
